# TrajectIQ Dashboard

Standalone React dashboard for TrajectIQ regression reports. It is intentionally separate from Phoenix's frontend and ships with reproducible demo artifacts generated by the TrajectIQ CLI.

## Run

    pnpm install
    pnpm dev

Open the Vite URL shown in the terminal. Use the scenario switcher to compare the blocked baseline-to-regression run with the passing baseline-to-fixed run. The tabs show the release overview, affected tasks, and first divergent tool step.

Use Import JSON in the header to load a file made with the trajectiq-dashboard-data CLI command. The imported artifact must contain report, diagnoses, and gate sections.
